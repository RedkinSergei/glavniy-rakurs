1. Цель задачи
Провести два типа правок:
•	Сменить акцентный цвет сайта с голубого (#3B82F6) на изумрудный (#10B981) — сохраняя тёмный navy-фон.
•	Заменить оффер «Бесплатный тест» на платный: «Первый объект — 990 ₽», с золотой кнопкой (#D4A847).
Структура страниц, блоки, типографика и тёмный стиль не меняются.

3. Детальные правки: замена цвета
3.1. CSS / переменные
Если в проекте используются CSS-переменные или Tailwind-конфиг, заменить значение в одном месте:
/* ДО */
--color-accent: #3B82F6;
/* ПОСЛЕ */
--color-accent: #10B981;

Если CSS-переменные не используются — заменить все вхождения #3B82F6 через поиск по проекту.
3.2. Навигация — кнопка «Бесплатный тест»
Изменить стиль кнопки в хедере:
/* ДО: голубая */
background: #3B82F6; color: #FFFFFF;
/* ПОСЛЕ: золотая */
background: #D4A847; color: #0F172A;
Текст кнопки меняется отдельно — см. раздел 4.
3.3. Выделенные слова в заголовках
На странице есть заголовок с выделенным словом голубым цветом (пример: «пролистывают»). Изменить:
<span style="color: #3B82F6">пролистывают</span>
/* ПОСЛЕ: */
<span style="color: #10B981">пролистывают</span>
Применить для всех аналогичных span-акцентов на всех страницах.
3.4. Иконки в карточках
В секции «Проблема» три карточки с иконками. Текущий цвет иконок — коралловый (~#F87171 / розово-красный).
Новый цвет иконок и их подложки:
•	Цвет иконки: #10B981
•	Фон-подложка иконки: #064E3B (тёмно-изумрудный, не чёрный)
Иконки — SVG или font-icon. Цвет менять через fill / color, фон — через background или background-color на обёртке.
3.5. Hover-эффекты и границы
Все элементы, которые при наведении подсвечиваются голубым (#3B82F6), заменить на изумрудный (#10B981). Это касается:
•	Пунктов навигации
•	Карточек в портфолио
•	Активных шагов в секции «Процесс»
•	Любых border/outline акцентного цвета

4. Замена оффера: «Бесплатный тест» → «Первый объект — 990 ₽»
4.1. Кнопка в хедере (навигация)
Параметр	ДО	ПОСЛЕ
Текст кнопки	Бесплатный тест	Попробовать за 990 ₽
Фон кнопки	#3B82F6 (голубой)	#D4A847 (золото)
Цвет текста	#FFFFFF (белый)	#0F172A (тёмный)
Размер шрифта	Без изменений	Без изменений
Border-radius	Без изменений	Без изменений
4.2. Hero-секция — CTA-кнопка
Если на главной странице есть большая CTA-кнопка внутри hero-блока (под заголовком) — применить те же изменения:
•	Текст: «Попробовать за 990 ₽ →»
•	Фон: #D4A847
•	Текст: #0F172A
4.3. Текст рядом с кнопкой (если есть подпись)
Если рядом с CTA есть подпись вида «Бесплатно, без регистрации» — заменить на:
Один объект, полный анализ. Без подписки.
Если подписи нет — пропустить этот пункт.
4.4. Якорные ссылки и href
Убедиться, что кнопка ведёт на форму или страницу оплаты. Атрибут href / onClick не должен вести на устаревшую форму «бесплатного теста».

5. Что НЕ менять
Во избежание лишней работы — явный список неприкосновенных элементов:
•	Тёмный navy-фон (#0F172A, #1E3A5F) — без изменений
•	Типографика: шрифт, размеры, межстрочный интервал
•	Структура и порядок блоков на странице
•	Текстовый контент (кроме кнопки и подписи к ней)
•	Изображения и портфолио
•	Логотип «ГлавныйРакурс»
•	Мобильная вёрстка — только цвета, без изменений layout
